# Weight

Body weight in pounds. The latest weight also sets the daily protein goal
(1 g per pound).

## How it's said

- "weight 231.4" / "weighed 229 this morning" / "I'm 230"
- "down to 228"

## Rules

- Pounds. A kilogram reading is converted (1 kg = 2.2046 lb) and the
  original noted in `notes`.
